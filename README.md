### 👨‍💻 Sobre Mim

🎓 **Bacharel em Ciência da Computação** e apaixonado por **Qualidade e Desenvolvimento de Software**.

💼 Atualmente, sou **Analista de Qualidade de Software (QA) Júnior na Zscan Software**, atuando diretamente em ambientes ágeis (Scrum/Kanban). Meu foco é unir a visão crítica de qualidade e usabilidade ponta a ponta (E2E) com conhecimentos sólidos de programação (**Teste de Caixa Cinza**), garantindo excelência técnica desde a concepção do código até a entrega.

🚀 **O que estou fazendo agora:**
- 🧪 Executando testes ponta a ponta (E2E), funcionais, regressivos e de usabilidade, além de criar documentação técnica (**BDD/Gherkin**) e manuais de uso com gestão via **Jira** e **Zephyr**.
- 🔗 Realizando validações e automação de testes de API utilizando **Apidog** com scripts em **JavaScript**, além de consultas de integridade de dados no **SQL Server**.
- 🤖 Otimizando processos e análises de QA com Inteligência Artificial (**ChatGPT Business** conectado a ferramentas) e conduzindo estudos de viabilidade técnica para projetos de automação.
- 🛠️ Aprofundando conhecimentos em **TypeScript / JavaScript** e **Java / Spring Boot**, preparando a base para automação E2E (**Playwright**) e desenvolvimento de software.
